# 简易云盘项目-团队开发规范（全员遵守）
## 1. 分支规则
- 禁止在main主分支开展开发工作，所有成员仅在个人专属分支执行开发操作；
- 成员A开发分支：user-auth-module，负责用户认证模块；
- 成员B开发分支：file-hadoop-module，负责文件及Hadoop模块；
- 成员C开发分支：frontend-module，负责前端开发模块；
- 成员D开发分支：test-deploy-module，负责测试部署及文档汇总模块。

## 2. Git提交规范
提交备注统一格式：【姓名】完成xxx功能开发/优化
示例：【成员D】完善项目环境检查脚本、【成员A】完成用户登录接口开发及测试

## 3. 文件存放规则
- 后端所有业务代码，统一存放至backend目录下；
- 前端所有项目代码，统一存放至frontend目录下；
- 测试用例、部署手册、开发规范等文档，统一存放至doc目录下；
- 数据库建表、数据插入等脚本，统一存放至sql目录下。

## 4. 开发禁忌规则
- 禁止向仓库提交无用文件，包括target编译目录、node_modules依赖目录、各类日志文件*.log；
- 禁止擅自修改、删除其他成员分支下的文件及代码；
- 每日开发工作结束后，必须完成代码提交及远程推送，避免本地代码丢失。
