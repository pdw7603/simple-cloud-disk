# 云盘项目-文件操作模块接口文档
## 接口概述
该模块提供文件上传、用户文件查询、单个文件下载、文件删除四大核心功能，返回统一 JSON 格式数据，状态码 200 表示成功，500 表示失败。

## 1. 文件上传接口
- 接口功能：上传本地文件至服务器指定目录，并记录文件信息到数据库
- 接口路径：/api/file/upload
- 请求方式：POST
- 请求参数：
  - file_path：本地文件绝对路径（必填，字符串类型）
  - user_id：用户ID（可选，默认值 1，整数类型）
- 返回值格式：
  成功：{"code": 200, "msg": "文件上传成功", "data": {"file_id": 整数, "file_name": "字符串", "file_path": "服务器文件路径", "user_id": 整数}}
  失败：{"code": 500, "msg": "文件上传失败：错误信息", "data": null}

## 2. 用户文件查询接口
- 接口功能：查询指定用户的所有未删除文件列表
- 接口路径：/api/file/query
- 请求方式：GET
- 请求参数：
  - user_id：用户ID（可选，默认值 1，整数类型）
- 返回值格式：
  成功：{"code": 200, "msg": "查询成功", "data": [{"id": 整数, "file_name": "字符串", "file_path": "服务器文件路径", "file_size": 整数, "file_type": "字符串", "create_time": "时间字符串"}]}
  失败：{"code": 500, "msg": "查询失败：错误信息", "data": null}

## 3. 文件下载接口
- 接口功能：根据文件ID下载服务器上的物理文件至本地指定目录
- 接口路径：/api/file/download
- 请求方式：GET
- 请求参数：
  - file_id：文件ID（必填，整数类型）
  - save_local_path：本地保存路径（可选，默认 /opt/cloud-disk/download/，字符串类型）
- 返回值格式：
  成功：{"code": 200, "msg": "文件下载成功", "data": {"file_name": "字符串", "save_path": "本地保存路径"}}
  失败：{"code": 500, "msg": "文件下载失败：错误信息", "data": null}

## 4. 文件删除接口
- 接口功能：标记指定文件为已删除（逻辑删除），并非物理删除服务器文件
- 接口路径：/api/file/delete
- 请求方式：POST
- 请求参数：
  - file_id：文件ID（必填，整数类型）
- 返回值格式：
  成功：{"code": 200, "msg": "文件删除成功", "data": null}
  失败：{"code": 500, "msg": "文件删除失败：错误信息", "data": null}
