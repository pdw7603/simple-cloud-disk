# 简易云盘项目-终版验收标准
## 一、环境验收标准
1. 基础环境：Git、JDK、MySQL、Hadoop均正常安装，版本符合要求
2. 服务状态：MySQL服务、Hadoop集群全进程运行，端口无占用
3. 权限配置：HDFS目录/cloud_disk/upload权限为777，数据库root用户远程访问授权生效

## 二、功能验收标准
1. 用户认证模块：登录、注册、退出功能全部正常，参数校验、异常提示完整
2. 文件操作模块：上传、下载、查看、删除功能全部正常，支持指定格式/大小文件操作
3. 前后端联动：前端页面操作可正常调用后端接口，数据同步无误
4. 数据存储：用户数据写入MySQL，文件数据存入HDFS，无丢失/损坏情况

## 三、交付验收标准
1. 代码交付：所有成员分支代码已合并至main分支，无冲突、无冗余文件
2. 文档交付：测试用例、部署手册、排查手册、验收标准全套文档齐全，内容准确
3. 部署交付：可通过start-project.sh一键启动所有服务，stop-project.sh一键停止
4. 测试交付：所有功能测试用例执行通过，无未解决bug
