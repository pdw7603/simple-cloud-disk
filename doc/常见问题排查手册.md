# 简易云盘项目-常见问题排查手册
## 一、Git操作类问题
1. 推送代码报错：fatal: unable to access 解决方案：检查SSH密钥配置，重新执行ssh-keygen生成密钥并配置至GitHub
2. 分支切换失败：error: pathspec xxx did not match any 解决方案：执行git fetch origin拉取远程分支，再切换
3. 代码冲突：CONFLICT 解决方案：执行git pull origin 对应分支，手动修改冲突文件后重新提交推送
4. 提交无记录：nothing to commit 解决方案：确认文件已修改/新建，空目录需创建.gitkeep占位文件

## 二、环境部署类问题
1. MySQL登录失败：Access denied 解决方案：核对账号密码，执行mysqladmin -uroot password 重置密码
2. Hadoop进程缺失：jps无DataNode 解决方案：删除hadoop/data目录，执行hadoop namenode -format后重启集群
3. JDK版本异常：java: command not found 解决方案：执行export JAVA_HOME=/jdk安装路径，写入/etc/profile永久生效
4. 端口占用：Address already in use 解决方案：执行netstat -tulpn | grep 端口号，kill -9 进程号释放端口

## 三、服务启动类问题
1. 后端jar启动失败：no main manifest attribute 解决方案：确认jar包打包完整，重新执行mvn clean package打包
2. 前端启动失败：npm: command not found 解决方案：安装node环境，执行yum install nodejs -y
3. Hadoop启动卡住：waiting for datanode 解决方案：检查防火墙状态，执行systemctl stop firewalld关闭防火墙
4. 数据库连接失败：Could not connect to MySQL 解决方案：确认MySQL服务启动，执行systemctl start mysqld

## 四、功能测试类问题
1. 文件上传失败：HDFS权限不足 解决方案：执行hdfs dfs -chmod 777 /cloud_disk/upload授权
2. 用户登录失败：数据库查询无结果 解决方案：检查数据库连接配置，确认用户数据已插入cloud_disk库
3. 页面访问失败：Connection refused 解决方案：检查后端服务是否启动，确认端口未被占用
