# 简易云盘项目-部署操作手册
## 一、部署环境要求
1. 基础环境版本要求：Git 2.0+、JDK 1.8+、MySQL 5.7+、Hadoop 3.0+
2. 运行权限要求：使用root用户或具备系统管理员权限的账号操作
3. 项目仓库地址：git@github.com:pdw7603/simple-cloud-disk.git

## 二、项目部署前置操作步骤
### 1. 拉取项目代码至本地服务器
cd /home/root
git clone git@github.com:pdw7603/simple-cloud-disk.git
cd simple-cloud-disk

### 2. MySQL数据库环境配置
1. 登录本地MySQL服务：mysql -uroot -p
2. 创建项目专用数据库：create database cloud_disk default charset utf8mb4;
3. 执行项目数据库初始化脚本：source /home/root/simple-cloud-disk/sql/cloud_disk.sql;
4. 配置数据库访问权限：grant all on cloud_disk.* to 'root'@'%' identified by '你的MySQL登录密码';
5. 刷新数据库权限配置：flush privileges;
6. 退出MySQL命令行：exit;

### 3. Hadoop分布式文件系统配置
1. 启动Hadoop集群所有服务：start-all.sh
2. 验证Hadoop服务状态：jps
3. 验证标准：需显示NameNode、DataNode、ResourceManager、NodeManager进程，进程均运行即为正常
4. 创建项目文件存储目录：hdfs dfs -mkdir -p /cloud_disk/upload
5. 配置目录访问权限：hdfs dfs -chmod 777 /cloud_disk/upload

## 三、项目服务启动步骤
1. 回到项目根目录：cd /home/root/simple-cloud-disk
2. 启动后端业务服务：cd backend && java -jar cloud-disk.jar
3. 启动前端页面服务：cd frontend && npm run dev
4. 服务启动验证：访问前端指定访问地址，能正常打开项目登录页面即为启动成功

## 四、项目服务停止步骤
1. 停止前端服务：执行kill -9 前端服务进程号
2. 停止后端服务：执行kill -9 后端jar包进程号
3. 停止Hadoop集群服务：stop-all.sh

## 五、部署常见问题处理
1. 拉取代码失败：检查服务器网络连通性，确认SSH密钥已配置至GitHub账号
2. 数据库连接失败：核对数据库地址、账号、密码配置，确认数据库服务已启动
3. Hadoop服务启动失败：检查Hadoop配置文件正确性，执行hadoop namenode -format重新格式化
4. 端口占用导致服务启动失败：执行netstat -tulpn | grep 端口号，定位占用进程并结束
